12. 專案摘要（300字以內）

本提案在於善用台灣本土興盛與豐富的佛教中華禪經典文物，包括已存的數位保存歷代大師的開示與對話，以及正在與未來在各地方道場的資料收集，將他們用在訓練，用改革性的微調工程或算法，產生並持續提供一個賦予佛系特色的台灣禪師級的開源語言大模型，並開發多重前端應用給大衆，包括問答，協助閲讀經文，提供地方口語的解釋。這些應用將使用在手機與智慧音箱，並以開源的方式達到普及目的。

13. 專案動機

台灣對漢傳佛教的保留和傳承以及經典數位化的成就是非常少數爲人所知的事實。但也是一個非常大的遺憾。目前團隊的觀察是沒有一個及時將這些文物以及多媒體展示給世人知道的系統化方式。在資訊技術日新月異的時代，如果沒有及時地去對這方面做多點的努力，那前人辛苦的纍積就沒有辦法得到收成。本專案的動機其實是在參加一個佛教活動時，收到一個智慧音箱，有個佛學小助手的功能，但是苦於後端的自然語言服務來自對岸，又其實已經沒法運行，所以有了去瞭解台灣本土的現代佛教數位化的念頭。後來看到有像法鼓的文化機構和資源，才想用開源，大模型，自然語言和多模型的處理概念。期待這是個源自台灣，放眼世界的項目。

15. 專案技術可行性

計劃使用AI技術如下：
1. 基礎大模型：使用目前被積極開發如ChatGPT 4.0 或 LLaMA2類型大模型。此類大模型已經有很多demo，以及特定領域的demo（例如 twllm.com 是針對台灣語料的大模型）
2. 微調技術：使用Parameter Efficient Fine Tune (PEFT)在特定領域對大模型做微調, 目前已知如 https://deerpark.ai/ 的demo是使用大藏經做PEFT微調

16. 專案可應用之情境說明

1. 對答系統（GPT）：使用者提出任何對漢傳佛教（汎指佛教，因爲使用者并無任何假設立場）的問題，本系統提供可能的答案，並進行多輪對話。本系統為模擬禪師的開示的例子，除了給與相對的問答，如有相關，希望能以以往聖嚴法師的開示（多媒體）回復使用者。
2. 語言支持：基於使用英語的使用者其實苦無此類服務，也能推廣本專案，使用者可以使用英文，系統提供雙向翻譯功能。影片和語音的部分，提供字幕以供理解。（長期計劃為提供原語音支持)
3. 閲讀以及瞭解經文: 提供使用者經文預讀指引，提供白話解釋（或由影片導引）。使用者可以向系統提出針對經文的問題，系統提供對答。
4. 數位化建立使用者的反饋用於自動微調: 本系統建立使用者反饋以及評分機制，能用於算法精進，完善回復的滿意度，以及及時對相關内容做調整。

17. 專案預期效益與社會貢獻

專案預期能提供大致兩個面相的服務：
1. 針對幫助台灣本身的佛學文案以及多媒體的數位話整理
1.1 發揮台灣本土已纍積的佛學資源，增加知識與認知的能力
1.2 經由開源，獲取台灣以外的資源，讓更多人擁有與使用這些服務
2. 針對社會普羅大衆的佛學認識，破除非正信的非正常宗教指引
2.1 有通用，普及，免費的服務，消除認識宗教的壁壘，免於錯誤和誤導
2.2 讓宗教能儘所能發揮平穩社會，與安靜人心的功能
