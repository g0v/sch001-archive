提案人 PeterWolf
第二梯（2024/02/21 - 2024/03/17）

在大型語言模型的 AI 時代背景下，臺灣的中文語料量級遠低於簡體中文語料量的問題，已觸發諸多國產 LLM 專案的啟動。諸如 TAIDE、MTK、NTU 及 CKIP …等團隊皆取得或大或小的進展。 相較於繁體中文語料，臺灣南島語族的語料資源更是少得可憐，以致於前述專案都停在國語、台語(閩南語) 或客語的階段。 本專案將利用 Articut 的語言學演算法，利用其「只需要極少極少語料」之特色，挑選一個較多人使用的南島語語言 -- 以排灣語為例 -- 做為實作「排灣語自然語言處理 AI 基礎建設」的目標。

12. 專案摘要（300字以內）

許多人以為南島語和英文一樣以空格隔開詞彙，故不需要分詞。事實上並非如此。

本專案包含三項目標，彼此對後續應用層層相依：

  1. 分詞
  2. 詞性標記
  3. 語意計算

以 cengelj 一詞為例。若前面加上 masi (帶…) 則 cengelj 的語意就會從「中午」變成「午餐」，而 masi cengelj 的意思就是「帶便當」。因此分詞標記應將 masi cengelj 標記為一個詞而非以空隔分開的兩個詞以維持它的意義。此為目標一。

其次，將 masi cengelj 標記為動詞，才不會因為 cengelj 的原始語意「中午」而將整句所指涉的時間縮限在中午。此為目標二。

目標三將算出句子裡的「人、事、時、地、物」即可被計算以做為後續 NLP 應用的基礎。藉由本專案成果即可設計「排灣語 - 中文自動翻譯系統」或是「排灣語文法自動檢查系統」…等資訊服務。

13. 專案動機

身為一個同時具備現代語言學背景和資訊能力的語言科技公司負責人，我深知全球主流的AI 科技發展脈絡、技術背景的限制以及市場規模。從這三個角度來看，南島語族的任何一種語言都將在大數據的基本條件下加速消亡。專案團隊中的語言學家們，更是將「語言的活用與保存」視為志業的一部份。

南島語言的保存並不只是建立資料庫就夠了，那只是將語言製成標本存放在博物館而已。語言的保存應該是找到方法和設計工具，使得南島語可以成為一個被現代資訊工具做為南島語言的使用者日常的輸入、搜尋系統的索引、AI 技術的操作…等等的一部份時，該語言才會繼續活著。

但因為主流的 AI 科技一方面需要足量的資料和運算力做為基礎，而這兩個技術背景限制在缺代市場規模的條件下，是不會受到資本家的青睞的。

正因如此，我們身為深知如何利用語言學知識，設計一個不需大量語料，也不需要高規格的運算力的語言科技團隊，正如蜘蛛人電影中的班叔所說的「能力愈大，責任愈大」，我們希望能善用這次 g0v 零時小學校的開源實踐計劃的資源，將我們擅長的「小數據」NLP AI 技術實作在排灣語上。同時，也藉著開源的機會，讓更多人看到利用小數據來做 NLP 基礎建設的方法，讓在全球語言尺度之下同屬「低資源語言」的臺灣繁體中文看到不同的方法論。

14. 專案設計概念以及與主題的相符性

我們預計採用現代語言學 X-bar 理論中的架構做為設計與實作本專案的方法。X-bar 理論可通用於全人類的語言，並用以解析人類語言的詞彙結構、句法結構並做為語意計算的框架。

預計將會有「自動分詞」、「自動標記」以及「語意計算」三大功能。

相符主題「Benchmark 臺灣觀點的評測」，是為了能建立南島語族的語言科技工具以解析其內涵，，否則，一個號稱能代表臺灣觀點卻卻無法納入臺灣南島語族觀點的系統，將會是漢字文化本位的觀點，而非真正的臺灣觀點。

此外，本專案的實作目標明顯相符「其他語言考慮，台語、客語、原住民族語」的主題。

16. 專案可應用之情境說明

MTK (聯發科) Research 日前釋出與 GPT3.5 同等級的繁中/英文 LLM — BreeXe-8x7B，正是基於 Mixtral-8x7B，並進行了「詞表擴充(連結)」後實作而成。

既要做詞表擴充，就必然要有詞表。而本專案的完成，洽好可以產生大量正確切分的排灣語詞彙以供整理成為擴充 LLM 所用的詞表。

此外，藉由本專案底層和其它 Articut 系列姐妹作 - Articut 中文版、Articut 英文版…等成果具有相同的框架的特性，甚至可延伸設計「排灣語 - 中文自動翻譯系統」或是「排灣語文法自動檢查系統」…等資訊服務。

17. 專案預期效益與社會貢獻

大型語言模型的誕生，一方面讓許多語言科技的應用得以實現，另一方面也加速了「語言量級霸權」現象的發生。主流的資料所使用的語言 (例如英文、西班牙文) 透過 AI 工具，將大大地壓縮其它非主流的資料所使用的語言 (例如繁體中文，或是比繁體中文更少使用者的臺灣南島語) 的使用機會和應用空間。

本專案透過實作基礎建設的方法以及語言學 X-bar 理論框架的特性，除了可以產生一個應用彈性非常靈活的系統，可做為南島語語意搜尋引擎的核心元素之外，亦可以產生給 LLM 做為擴充詞表的輸入工具，以擴展開源 LLM 模型的低資源語言 -- 南島語的支援能力。

21. 專案期中與期末規劃

依過往其它語言版本 Articut 的開發經驗，將需要 4 位全職開發人員 14 個月的時間，才能完成。因本計劃最高補助金額為 50 萬元，約能支應團隊 4 個月的開發支出，因此我們將致力於優先完成系統框架，並以目前已掌握的多本排灣語文本 (包括歌詞、福音書…等) 做為優先測試資料。

我們預計在獲選後依以下進度進行：

  • Start Date + 35 天：完成軟體系統框架設計與實作；
  • Start Date + 45 天：完成排灣語的人稱、數字系統演算法，並開始延請熟悉族語者做驗證。驗證人力相當於 LLM 開發過程中 RLHF 的人力回饋支出。
  • Start Date + 60 天：完成測試用框架的設計與實作。並開始延請兼職人員將數位化後的排灣語聖經投入系統做雙語比對 (排灣語 vs. 中文/英文) 以確保處理結果的語意正確。
  • Start Date + 90 天：實作完成排灣語的「焦點系統」和「普通名詞」的演算法。額外延請爬蟲程式專業人員，以各線上族語資源內容設計自動測試流程。並以輸出之結果，持續交付熟悉族語者做正確性驗證。
  • Start Date + 120 天：實作完成排灣語的和「動詞系統」的演算法

前述演算法皆包含：

  1. 分詞模組
  2. 詞類標記模組
  • Start Date + 150 天：期末時間已過。但繼續實作語意計算模組。
  • Start Date + 190 天：以排灣語福音書進行測試和程式校正
  • Start Date + 260 天：以排灣流行歌曲的歌詞進行測試和程式校正
