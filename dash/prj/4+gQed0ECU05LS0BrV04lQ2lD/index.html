為什麼要做這個專案？（動機）

因為許多人都有破百人無法好好演講的困擾。
所以使用 Sync Slide 結合 Clubhouse + Gather Town
就可以解決多人演講，但台下人又持續互動的好效果。
未來就可以透過遠端的方式，舉辦一些國際破萬人的大活動

請以此句型釐清專案目標、受眾與獨特性：

想透過線上辦大型活動的都是我們合適的 User
另外對一般參與者來說，也比較方便，可同步用Gather Town 交流同步在手機上看到投影畫面並且聽到 clubhouse 上的講者聲音，全部都是即時的呈獻，不延遲。

請列出這個計畫的目標對象，他們的需求、情境與使用動機？

1. 大活動的人需要拓展到辦世界級的活動時，大企業會贊助，但目前就卡在百人問題。無法再向上拓展。
2. Gather Town User 可同時手機看見畫面與聲音來聽演講，但又可以在台下與其它人互動。目前 Gather Town Taiwan User Group 有 4k 人，又有許多人社群的人使用 GT。我們可以考慮用 Sync Slide 來辦國際型大活動，並且透過 clubhouse 將全球知名的人事都 join  在台灣人所辦的活動中。
