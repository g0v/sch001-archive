提案團隊簡介

台灣開放教育推動團隊是由在學學生、教育工作者、開放知識及開源社群參與者，所組成的自發性團隊，關心開放教育的學習資源，積極與民間開放教育資源交流討論，並整理資源供學生參考，實踐「Open for everyone, support for needed」的概念，讓課程開放給所有人，並給予足夠資源與協助給有進一步學習動機的學生、教育工作者。

為什麼要做這個專案？（動機）

OCW（OpenCourseWare）自2001年由美國麻省理工學院提出，台灣也於 2007 年由交通大學率先響應，許多大專院校紛紛跟進，建立豐富的線上課程資源。團隊成員本身也從國中生的學習情境中，了解相關課程資源，發現以下問題：

一、開放式課程資料分散，使用者需要多方查詢，不易促進整體資料分析與應用 🧐 目前各個平台網站其系統皆獨自運行，未有完整整合平台，依照團隊逐站瞭解，少數開放課程平台（如中華開放教育平台）有涵蓋尚未自行建立 OCW 網站的大專院校課程。但整體來說，仍未解決 OCW 之分散情形，依團隊成員檢索也尚未查得「開放式課程資料集」釋出，也因此許多的資料應用構想，例如「開放式課程-個人課表 app」、「同名課程跨校內容比較」等應用也甚為少見。

二、開放式課程資源，需要加強串接 U18 年齡層的學習情境 😎 U18 意即年齡層 18 歲以前，包含國高中學校學習歷程中，尚未有效整合開放式課程資源。例如國中的校內資訊領域課程提供入門類課程內容後，引介資訊領域的「開放式課程資源」，或是作為「高中自主學習」的資源等。

延伸課題包含：(1) 學生若完成 OCW 平台課程後，能否取得到相關認證或證明 (2) 許多 OCW 網頁已有長時間未更新 (3) 非大專院校所開設的線上特色課程，也期待能進行呈現給 U18 年齡層的學習者。（前述課題描述參考本團隊訪談六位國高中與大學生，回顧國中階段的資訊領域課程教學方式：https://bit.ly/3i5brEH，以及團隊成員包含國中教師與學生的現況經驗）

請以此句型釐清專案目標、受眾與獨特性：

為了解決個人學習者、自主學習推動單位與教育機關遇到的資源分散之蒐集上困難，我們的專案提供入口整合查詢平台，可以做到課程的整理與比較。我們的專案跟現有的跨校平台，在課程完整度與課程搜尋結果排行的演算法不同，因此具有不可取代性。

請列出這個計畫的目標對象，他們的需求、情境與使用動機？

一、提供「個人學習者」一個開放式課程整合查詢工具
對於學習者，本平台將能提供更好的學習體驗，進而提高學習效率。

二、提供「自主學習推動單位：組織、老師」輔助於課程資源籌備
透過本階段所完成的「課程整合查詢網頁、課程資訊資料集」等專案雛形，進一步諮詢國高中自主學習推動單位，進行專案意見蒐集。意見舉例例如期待能自行上傳符合 開放式課程 schema 資料格式的課程資料，以利課程資訊流通，或協助 OCW 課程的刊登與上傳。本專案所整理之 API 服務，亦可提供各類教育推動單位運用。

三、提供「教育機關與部門」安排進階學習資源
基於開放式學習風潮，教育部門各階段可掌握大專院校之開放式課程資源總覽，體制內教學可以更進一步搭配線上開放式課程，讓學生可以了解校內校外的學習資源指引。

你覺得本專案可能會面臨的困難有哪些，你又會如何解決這些困難？

本專案在營運上需要雲端主機等相關技術營運費用，因此在開銷方面，可能是我們將會遇到最大的困難。
我們預計會透過尋求企業贊助，籌措經費以保持平台的持續運作，也藉此連結更多元的網站推廣夥伴。

本專案結束後，未來可能進一步的發展？

一、Open Course Data/API 研提開放式課程的資料架構 (schema) 與資料交換方案
二、One-stop 建立一站式開放課程查詢網頁雛形
三、Co-work 與國內開放式課程營運單位、國高中階段的使用單位交流
