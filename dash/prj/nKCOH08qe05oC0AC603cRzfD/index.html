為什麼要做這個專案？（動機）

現有的教案共享平臺僅止於收集最終版本教案，格式也鮮少統一。當教師在不清楚他人教案設計的發想脈絡下使用其教案，可能導致偏離原設計者的核心理念；另外，在108課綱實行下，對於跨領域課程及特色課程的需求大幅提升，過去卻鮮有這類課程設計的紀錄。因此團隊想提供一個平臺，讓教案分享者能詳細記錄教案設計過程的發想，協助教師們在適應新課綱的同時減低課程負擔，提升教學者之間的交流共創機會，在開放協作的機制下也較能保障課程的品質。

請以此句型釐清專案目標、受眾與獨特性：問題的標題

為了解決體制內外教師遇到的教案協作、撰寫與交流的困難，此專案提供如 GitHub 管理程式碼的方式管理教案內容，開放教師們參考他人在教案發想過程的想法迭代，並交流使用，降低個人發想的瓶頸。此專案跟現有的教案共享平臺不同，除了蒐集教案成果，還希望記錄下發想過程的思考脈絡，因此具有不可取代性。

請列出這個計畫的目標對象，他們的需求、情境與使用動機？

體制內外教師可於平臺上搜尋教案，檢視更新歷程並參與協作，亦可自己建立教案，邀請合作的師長透過共同編輯的方式，留下教案的迭代與商討紀錄。尤其在新課綱實行後，倍受重視的跨領域課程與特色課程，對於教學現場老師而言都是新挑戰，此平臺提供的多方參照與協作機制將有助於降低教師設計課程的困難性。

你覺得本專案可能會面臨的困難有哪些，你又會如何解決這些困難？

對於使用者需求的了解仍不足。目前能接觸到的教師資源有限，希望能在平臺有基本雛型後，徵求各階段教師試用或填寫問卷，提供回饋協助團隊更新需求。
對於如何能夠系統性地紀錄下教案發想的脈絡仍須確認，如果能設計一套模板供教師紀錄發想過程，將可提升資料的易用性。設計的方式須徵求 UX 設計師協助。

本專案結束後，未來可能進一步的發展？

加入文字以外的教學媒材蒐集，提供更豐富的教材紀錄
