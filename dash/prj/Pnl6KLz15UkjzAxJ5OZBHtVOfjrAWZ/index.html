12.為什麼要做這個專案？（動機）

過往就讀中學期間，因為有「台師大物理動畫實驗室」（黃福坤教授），將抽象的物理範例具象化，受益良多。然而，當代網頁瀏覽器已不支援 Java applet，相關模擬動畫亦難再更新。

國外知名互動設計師 Bret Victor 的演講「Inventing on Principle」，其中程式開發互動性的概念已普及業界，知名案例便是蘋果的 Swift Playgrounds，在 iPad 或 Mac 上皆可使用。

本專案希望結合兩者概念，一方面為開源教育立下標竿，另方面得以推廣程式教育，促進教學相長。

13.請描述此專案使用者的故事，包含使用者身份、使用者遇到的困境、使用動機。

  1. 中學物理教師：授課形式往往受限於傳統的黑板書寫、公式推導。透過自由取用開源軟體，甚至自行客製開發教材案例，可以用於輔助教學，加深教學成效。
  2. 學習物理的學生：受限於上課的靜態教學或動畫呈現，可能難以理解物理。透過可操作的互動式軟體，得以加深對物理的理解，甚至透過修改程式碼，培養對程式開發的興趣。

14.專案預計提供何種解決方式，並請詳細說明其功能／服務

以 Swift Playgrounds 開發物理模擬軟體，只需有一台 iPad 即可編譯執行，得以配合行政院「生生用平板」方案配發之學習載具 iPad 9。功能目標為：

  1. 納入各種題型實例
  2. 以觸控為主要介面
  3. 降低開發門檻
  4. 每項物理模擬都提供自由操作模式，強化主動理解力

開發中的原型：intuiPhysics Free（在 iPad 上點擊連結後，再點選「在 Playgrounds 中打開」）。

15.目前已有哪些類似專案？請嘗試分析其不足需優化之處。（若目前無類似專案，請寫「無」）

PhET：由美國科羅拉多州立大學開發，可能是目前最熱門的輔助教材。

  • 動畫精緻，自訂性佳，支援多國語言，有離線版 App。
  • 缺點為實例較少，介面較為複雜。
  • 雖為開源專案，但難以自行擴充，因為開發門檻過高。根據官方文件指出，新加入的開發者需要長達 6-12 個月，才能熟悉 PhET 既有程式碼。

oPhysics（由退休中學物理教師 Tom Walsh 製作）、CoSci（國立中央大學劉晨鐘講座教授帶領開發）

  • 實例較多。
  • 大多為針對桌面電腦設計的介面，對於觸控介面較不友善。
  • 非開源專案，無法擴充。

20.你覺得本專案可能會面臨的困難有哪些？你將如何解決這些困難？

  1. 為納入各種題型實例，但數量頗多。預計透過實作基礎題型，讓教師們在開源架構下，自行發展特殊題型，並互相分享。
  2. 為降低開發門檻，但 SwiftUI 與動畫效果仍有一定門檻。預計透過妥善設計的軟體架構，使其易於客製修改。
  3. 為開發自由操作模式，可能需較長開發時程。
  4. 即使降低開發門檻與增加互動性，願意參與開發的教師、希望深入理解物理的學生數量仍少。預計廣泛接觸師生、與大學教授或教科書廠商洽談、增加多國語言等方式，來觸及更多潛在受眾。

21.專案目前需要哪些方面的幫助呢？

  1. 進入校園，與第一線的物理教師協作，合作教案設計等。
  2. 媒體宣傳資源。
  3. 美感教科書設計師。

22.本次專案孵化競賽後，未來可能進一步的發展？

以 108 課綱為準，優先實作國中與高中共同涵蓋範圍，如：能量的形式與轉換、溫度與熱量、力與運動、波動與光及聲音、萬有引力、電磁現象等。

目前僅與少數高中物理老師初步洽談概念，尚未進行更多推廣。
