12.為什麼要做這個專案？（動機）

透過資訊科技輔助教學，將能夠提供簡化的刺激環境、立即的回饋和反覆練 習的優勢，不僅能更容易引起輕度智能障礙學生的學習動機（張英鵬，1993；朱 6 經明、1995），更可以提升他們的學習成效（徐智杰，2002；黃錫昭，2003；張 競文，2006；楊春玉，2008）。為此，本作品希望能運用混合實境技術，並以Microsoft Hololens 2 作為學習輔具，透過虛擬物件操作的回饋，來為輕度智能障礙者提供 身歷其境的門市服務業職前訓練，其中包括了商品處理作業，以及簡易飲料機設 備操作等訓練項目。以混合實境的虛實整合技術來提供職前訓練，透過步驟性的 操作，讓他們可以更容易地學會工作技能，在提升智能障礙學生們學習動機的同 時，也幫助其去除預期失敗的心理障礙。在經濟方面，透過科技減少大量的人力 協助訓練，也因為混合實境的特性，無需借用實際的超商門市，就能進行沈浸式 的職前訓練，有效降低訓練所需的時間與人事成本。因此，我們希望能藉由本作 品，提升輕度智能障礙者們的勞動參與率，將非勞動力轉會為勞動力，進而降低 失業率。

14.專案預計提供何種解決方式，並請詳細說明其功能／服務

功能／服務

1. 商品整理模組

  • 虛擬環境呈現： 利用 Hololens 2 頭戴式顯示器，整合影像辨識與空間互動技術，模擬門市服務現場的各種場地，如倉庫和冷藏櫃，以培養商品整理的技能。
  • 步驟引導： 提供不同地點的商品排序步驟，引導學童挑選出過期商品。
  • 個別提示功能： 根據學童需求給予相應的提示，例如紅光或文字提示，以適應不同學習差異。

2. 飲品製作模組

  • 虛擬操作環境： 利用 Hololens 2 呈現虛擬環境，模擬各種飲品的製作場景。
  • 操作實踐： 包括杯子的選配、冰量的調整，以及配料的添加等實際操作，讓學童能夠正確製作符合客人需求的商品。
  • 即時反饋： 提供即時反饋，讓學童了解自己的操作是否正確，並即時進行修正。

3. 即時反饋與錯誤提示

  • 實時檢測： 系統能即時檢測和紀錄學童的答案或操作，提供即時的正確答案或指導。
  • 自我修正： 支援學習者了解自己的錯誤，並即時進行修正，強化學習效果。

4. 網站平台供教育人員使用

  • 數據整合： 架設網站平台，供教育人員透過網頁端協助整合 MR 設備蒐集的數據。
  • 圖形化呈現： 圖形化呈現學童的操作表現，以直觀的方式顯示學習進度和表現。
  • 數據分析和預測： 數據分析和預測功能，協助教育人員更精確地了解學童的訓練成效，進一步優化教學策略。

18.請列出專案使用到的數位工具及技術／程式語言

HoloLens 2

Microsoft HoloLens 2 為一臺混合實境頭戴顯示器，自身除了搭載數個攝像鏡頭、麥克風及螢幕顯示器，更配有完善的運算處理單元，透過先進的設備與技術支援，實現更精準的手部追蹤、眼球追蹤及語音辨識等功能。HoloLens 2 最大的優勢是適中的大小，能夠讓使用者更方便的攜帶。在配戴 HoloLens 2 時還具有可調節式的設計，加上其合理的配重，讓使用者能夠更舒適、更無負擔的配戴較長時間，而且不需要額外承接厚重的線纜，使用者可以自由地走動。拋下諸多舊有 AR、VR 限制的同時，更是替使用者打造了「沉浸式」的使用環境。

Unity

Unity 是跨平台的 2D 和 3D 遊戲引擎，其應用相當之廣泛，除了遊戲研發之外，還能廣泛用作建築視覺化、即時三維動畫等類型互動內容的綜合型創作工具。微軟推出的「混合實境開發工具組」，提供我們一系列的開發工具，讓我們在系統的開發上更精確且更有效率。

MRTK

Mixed Reality Toolkit（MRTK）是一個開放原始碼的跨平台開發套件，能夠快速創建適用於多種平台的混合實境應用程式，包括 Microsoft HoloLens、Windows Mixed Reality 和 OpenVR。MRTK 提供各種功能和工具，使開發人員能夠輕鬆地將手動追蹤、UI 控制元件等集成到應用程式中，同時支援手勢、語音識別和眼神追蹤等功能，為跨平台系統提供強大的基礎。

Vuforia

本專案結合 Vuforia 和 HoloLens 的相機，利用 Vuforia 輔助空間追蹤功能，降低相機視野內的干擾，實現更穩定的目標追蹤。同時，Vuforia 提供實體物件辨識功能，例如辨識機器、汽車或玩具，用以指引使用者在真實環境中進行更明確的操作。

Visual Studio 2019

Visual Studio 2019 提供了一個強大的開發環境，可以與我們使用的 Unity 無縫整合，讓我們能夠輕鬆的創建 HoloLens 應用程序。但在使用之前，需確保在 Visual Studio 2019 中，已安裝 HoloLens 的工作負載（如：Universal Windows Platform (UWP)、Windows SDK、Visual Studio Tools for Unity 等）。

20.你覺得本專案可能會面臨的困難有哪些？你將如何解決這些困難？

本專案可能面臨的挑戰及解決方法

1. 技術整合挑戰

  • 困難： 整合HoloLens硬體、Unity引擎、MRTK和Vuforia等多種技術，可能面臨相容性和整合的技術挑戰。
  • 解決方法： 建立詳細的技術架構和測試計畫，逐步整合各項技術，進行系統級和單元級測試，確保每個組件的相容性和協同運作。

2. 使用者體驗優化

  • 困難： 提供優良的使用者體驗在混合實境中是一項挑戰，需要克服虛擬和現實世界的交互問題。
