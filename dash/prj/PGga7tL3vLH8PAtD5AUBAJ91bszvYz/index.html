為什麼要做這個專案？（動機）

發現很多活動太少人參加。

請以此句型釐清專案目標、受眾與獨特性：

為了解決活動主辦者與想參加活動的青少年遇到的很多活動太少人參加的困難，我們的專案提供一個平台，可以做到宣傳活動，進而達到「減少資訊不平等以及認識更多和自己興趣相近的人」。我們的專案「台北市青少年活動平台，在活動類型數量與內容挑選不同，因此具有不可取代性。

請列出這個計畫的目標對象，他們的需求、情境與使用動機？

目標對象 : 青少年
需求 : 學習新知識、認識跟自己興趣相近的人
情境 : 只學習學校教的東西，文化、藝術相關的很少
使用動機 : 能學到新知識、認識跟自己興趣相同的人
